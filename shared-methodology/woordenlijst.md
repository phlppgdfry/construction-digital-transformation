# Woordenlijst

Bouw, recyclage en IT in gewone taal. Alfabetisch.

| Term | Betekenis |
|---|---|
| **ADKAR** | model voor verandermanagement: Awareness, Desire, Knowledge, Ability, Reinforcement ([verandermanagement](verandermanagement.md)) |
| **ADR** | Architecture Decision Record: één architectuurbeslissing met context, alternatieven en gevolgen ([ADR's](adr/README.md)) |
| **Acceptatielijst** | de lijst van afvalstoffen die de breekwerf volgens de milieuvergunning mag aanvaarden, en die ze moet weigeren |
| **AS-IS / TO-BE** | het proces zoals het vandaag loopt / zoals het moet lopen |
| **BABOK** | Business Analysis Body of Knowledge, de standaard van IIBA voor business analyse ([mapping](babok-mapping.md)) |
| **Baseline** | de afgesproken versie van de requirements waarop gebouwd wordt ([governance](governance.md#baseline)) |
| **Benefits map** | schema van wat je bouwt → wat er in het werk verandert → welke baat → welk doel |
| **Benefits review** | de evaluatie na go-live: zijn de beloofde baten er? |
| **BPMN** | Business Process Model and Notation, de standaardnotatie voor processchema's |
| **Bruto / tarra / netto** | gewicht van de vrachtwagen met lading / zonder lading / het verschil, de lading zelf |
| **Code app** | Power Apps-app geschreven in code (React, TypeScript) in plaats van met de canvas-ontwerper |
| **Confidence** | hoe zeker de AI is van een gelezen veld, tussen 0 en 1 |
| **Connection reference** | verwijzing in een solution naar een verbinding, zodat de solution in een andere omgeving met andere accounts werkt |
| **Dataverse** | de databank van Microsoft Power Platform, met relaties, sleutels, beveiliging en audit |
| **Dead-letter** | een bericht dat na alle pogingen niet verstuurd raakte en nu een mens nodig heeft |
| **Depot** | opslagplaats van materialen (granulaten, buizen) |
| **DPIA** | gegevensbeschermingseffectbeoordeling: verplicht bij een hoog privacyrisico ([privacy](privacy-en-data.md)) |
| **DT-02 / DT-03** | beslistabel voor wie een schadeclaim / materiaalaanvraag goedkeurt |
| **ERP** | het kernsysteem voor financiën, voorraad, aankoop en projecten |
| **ERP-facade** | eigen API-laag tussen de apps en het ERP, zodat een ERP-wissel alleen de facade raakt ([ADR-002](adr/ADR-002-erp-facade.md)) |
| **Flow** | Power Automate-flow: een automatische reeks stappen die start op een gebeurtenis |
| **Go/no-go** | de beslissing van de proceseigenaar dat de organisatie klaar is om live te gaan |
| **Granulaat** | gebroken steen of puin in een bepaalde korrelgrootte (bv. 0/31,5), vaak gerecycleerd |
| **Grondoorzaak** | de oorzaak die, als je ze wegneemt, het probleem echt oplost (vijf keer waarom) |
| **Identificatieformulier** | wettelijk document dat afvaltransport traceerbaar maakt |
| **Idempotent** | twee keer hetzelfde doen geeft hetzelfde resultaat als één keer: een tweede boeking met dezelfde sleutel wordt niet geboekt |
| **Idempotency-key** | de vaste sleutel van een bericht (bv. `wb-WB-26-04222`) waarop het ERP dubbels herkent |
| **KLIP** | Kabel- en Leidinginformatieportaal: wie graaft, vraagt vooraf de ligging van kabels en leidingen op |
| **KPI** | Key Performance Indicator: een gemeten getal met een definitie, een bron, een nulmeting, een doel en een eigenaar ([KPI-framework](kpi-framework.md)) |
| **Leading / lagging indicator** | vroege aanwijzing dat het werkt / het uiteindelijke resultaat ([meetplan](meetplan.md)) |
| **Materieel / materialen** | machines en werktuigen / wat in het werk verwerkt wordt. Case 03 gaat over materialen |
| **Model-driven app** | Power Apps-app die Power Platform zelf opbouwt uit de tabellen, weergaven en formulieren |
| **MoSCoW** | prioriteit: Must, Should, Could, Won't (deze fase) |
| **MVP** | Minimum Viable Product: de kleinste versie die echte waarde levert en iets leert |
| **Nulmeting** | de meting vóór de verandering, om achteraf te kunnen vergelijken |
| **Optie 0** | wat er gebeurt zonder (nieuwe) software: altijd de eerste optie om eerlijk te vergelijken |
| **Outbox** | tabel met berichten die nog naar het ERP moeten; een aparte flow verstuurt ze met nieuwe pogingen ([ADR-004](adr/ADR-004-outbox-idempotency.md)) |
| **Power Fx** | de formuletaal van Power Platform |
| **RAID** | Risks, Assumptions, Issues, Dependencies: één log voor alles wat het project kan doen ontsporen |
| **Regelcatalogus** | alle bedrijfsregels met parameter, eigenaar en reden ([regelcatalogus](regelcatalogus.md)) |
| **Replay** | de nieuwe regels toepassen op oude gevallen, om te zien wat ze gedaan zouden hebben |
| **Requirement (business, stakeholder, solution, transition)** | de vier BABOK-soorten: wat de organisatie wil, wat een rol nodig heeft, wat de oplossing doet, wat nodig is om over te stappen |
| **Schaduwdraaien** | de nieuwe oplossing draait mee zonder effect, en wordt vergeleken met de oude werkwijze |
| **SLA** | afgesproken termijn waarbinnen iets moet gebeuren (hier: de beoordeling van een schadedossier) |
| **Solution** | in Power Platform: het pakket met tabellen, flows, apps en instellingen dat je naar een andere omgeving brengt |
| **Spoed** | een materiaalaanvraag voor levering binnen 48 uur |
| **Stabilisé** | mengsel van zand en cement voor funderingen, op bestelling geproduceerd |
| **Traceerbaarheid** | (requirements) de lijn van pijnpunt tot test en KPI · (afval en grond) het document dat herkomst en bestemming aantoont |
| **UAT** | User Acceptance Test: de gebruikers testen of het doet wat afgesproken is |
| **Weegbon** | het ticket van de weegbrug met bruto, tarra, netto, klant, nummerplaat en materiaal |
| **Werfleider / projectleider** | leidt de werf ter plaatse / is verantwoordelijk voor planning, budget en marge van één of meer werven |
